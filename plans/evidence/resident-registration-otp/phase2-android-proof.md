- Thirty-second request watchdogs release visible loading without abandoning transport ownership. Competing Auth/profile mutations remain blocked until transport settlement. OTP resend uses an email-free persisted deadline, recomputed on foreground/restart. Unknown profile writes require reload/review; unknown password writes require confirmation of the exact entered credential with an independent non-persisting client or recovery.
- New prerequisite migration `0108_resident_profile_completion_conflict_guard.sql` adds a caller-only RPC with an atomic full-row snapshot comparison, the established advisory/row locks, and delegation to the existing completion operation. Old callers are unchanged. Null snapshot expects no profile; stale snapshots return `PT409`/HTTP 409 without writes. No new tables or lifecycle/credential backfill.
- Native PKCE originally warned that WebCrypto was unavailable and fell back to a plain challenge. The SDK's optional flow-ID redirect experiment remains disabled; Auth starts/exchanges stay serialized rather than changing shared redirect policy.
- Password drafts live only in the account-keyed wizard's memory, survive details/password back/forward, and clear on successful creation, recovery navigation or wizard/account teardown. Unknown password writes block back/skip until exact-credential confirmation or recovery. These final UI-state refinements pass types/lint/export; development-build interaction proof remains pending.
