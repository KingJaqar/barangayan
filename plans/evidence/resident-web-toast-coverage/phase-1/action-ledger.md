Existing behavior is listed separately from the later terminal owner. Every row was checked against the source and caller inventory; no real external action was exercised.

Paths below are relative to `apps/resident-web/src/`. Function names identify the existing owner precisely. Line numbers in `notification-calls.tsv` anchor existing calls; the source files themselves are unchanged. When a row says “attempt,” later wiring should issue one adapter attempt only for an accepted explicit activation, retain the existing entity/account identity and stale guard, and never issue a new ID for a repeated callback. No new business requests, changed predicates/payloads, or retimed operations are proposed.
