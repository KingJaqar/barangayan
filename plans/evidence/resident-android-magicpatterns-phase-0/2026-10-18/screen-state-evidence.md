## State-variant status policy

Every variant named below is **native pending manual verification** in Phase 0, with no pass inferred from source/tests/prototype. The table above preserves narrower reference observations and the exact remaining browser gaps. Unavailable backend/account/permission variants are deferred to their owning packet, never simulated as product success. No additional fixture was created by changing real data.

- **All data screens:** initial loading, loaded, empty, error/retry, slow refresh with existing content retained, long text, missing optional media, stale/deleted record, guest and signed-in variants where reachable.
- **Home/services:** zero/one/multiple/overflow cards; request sheet open/closed; each status/progress segment; every request filter/subfilter; ID verified/checking/unverified/failed/unavailable; free/fixed/per-page/assessed-at-pickup fees; purpose Other; renter upload; canceled picker; upload errors; busy/success/failure submission; legacy form.
- **Payment:** method unset/pickup/QR, page count required, unknown fee, free/waived, settlement feature disabled, pending session, under-five-minute warning, expired/cancelled/paid/refunded/completed, save/share denied, payment cancellation race, receipt unavailable/retry. Keep state labels based on existing authoritative state.
- **DRRM/maps:** guideline closed/open; routing summary expanded/collapsed; list/map/sort; selected/deselected center or incident; filters hidden/visible and multiple selected; no search matches; map initializing/error; unknown/denied/granted location; pending/confirmed/poor/outside origin; no pack/stale/corrupt/unavailable pack; offline/online; closures/avoidance/no route; tabs temporarily hidden/revealed; occupancy zero/high/full/unknown capacity.
- **Scan/family/alerts:** guest gates, scanner pending/denied/live/closed/result/error, repeated-scan lock, center picker empty/selected, QR loading/share/download failure, family empty/add/edit/remove/error and cross-screen refresh, period/partial-date/exact-date/clear filters, valid leap-day and month-end wheel positions.
- **Health:** collapsed/expanded calendar, month/year jump, selected/adjacent-month dates, category and month-wide filters, no drives, eligible/ineligible/full/already registered, every registration status, detail sheet, member picker, None versus multiple comorbidities, vaccination-only dose control, consent off/on, duplicate/stock race, submission error/success and confirmed server number.
- **Reports/news/search:** all actual statuses and read/unread states, mark-all zero/nonzero, no photo/one/many photos, wrapping detail carousel and single-photo full-screen open/close, location picker cancel/confirm/denial, trash-category zone selection, title/field limits, withdrawal eligible/expired/denied, confirmation eligible/already confirmed, announcement deep-open/media/body, search empty/history/suggestion/query/partial result/error/no result, clear/back/refocus and cross-account history isolation.
- **Settings:** guest restrictions; all theme/accent/font settings, custom-color empty/full/duplicate/long-press/save/cancel, password/account-state modes, export formats/error/share cancellation, delete confirmation/reauthentication/cancel, profile unchanged/invalid/dirty/saved/photo failure, every ID step and replacement/pending/failed state, email cooldown/invalid/expired/mismatch/verified, location saved/changed/outside/geocode failure, FAQ categories/article errors, both legal tabs and expanded history.

Later-phase-only variants stay explicitly deferred; Phase 0 does not execute all later workflows. Representative list/form/core controls and guest/signed-in fixtures are captured.
